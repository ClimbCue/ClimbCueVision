# ClimbCue Vision Lab

攀岩视觉分析与指导原型：将**同一瞬间的人体姿态、岩点信息和原始画面**交给大模型，结合攀岩知识生成一条简短的下一步提示和详细指导卡片。两版目前都在网页展示，便于对照测试。

**当前阶段：本机视觉感知 + 云端快照指导 + 本地知识库。语音功能暂缓，不在当前开发与验收范围内。**

## 功能状态与页面入口

| 模块 | 当前状态 |
| --- | --- |
| [姿态与指导页](http://127.0.0.1:8000/pose) | 摄像头、上传视频、两段项目测试视频；6 种姿态模型切换，关键点、角度、运动指标和数据导出 |
| 岩点标记 | 多颜色自动找候选、画面取色、手动圈选/拖动/缩放/重画/删除/撤销、3 种 SAM 系列模型、批量选点与确认 |
| 下一步指导 | JoyMaas Qwen3.6 图片与结构化观测输入；同帧快照、眼镜短句、网页详细卡片及岩点可视化 |
| [知识库页](http://127.0.0.1:8000/knowledge) | 中文检索、来源摘要、恢复拉伸专题、视频目录、笔记/字幕导入；可另行配置大模型 RAG |
| AI 眼镜 | 已有网页显示预览与指令 JSON 导出；尚未连接实体眼镜 |
| 全云端姿态与分割 | 尚未实现；本机视觉模型仍为当前感知来源 |
| **语音识别、语音指令、语音播报** | **暂缓：本阶段不接入 ASR/TTS，不做麦克风交互、语音对话或眼镜语音输出** |

语音暂缓不影响文字提示、视觉卡片、视频播放或已有字幕文本导入；视频自动转录也未实现。后续是否恢复语音开发另行确定。

## 快速启动

需要 Python **3.11 或 3.12**、uv、Node.js 20+。推荐 Chrome/Chromium；浏览器自动化测试使用本机 Chrome。已有模型实测环境为 Apple M2 / 16 GB / macOS 13.5，Python 3.12。

在项目根目录执行基础安装：

```bash
uv sync
npm ci
npm run setup:pose
```

安装 Python 视觉依赖及模型，以启用 RTMPose、YOLO、SAM 和颜色识别完整流程：

```bash
uv pip install --python .venv/bin/python -r requirements-models.txt
npm run setup:models
```

启动服务：

```bash
.venv/bin/python -m uvicorn web.app:app --host 127.0.0.1 --port 8000
```

打开 <http://127.0.0.1:8000>，默认进入姿态页。仅完成基础安装也可使用浏览器 MediaPipe、手动标记和本地知识检索。

首次下载需要网络。`setup:pose` 准备 MediaPipe WASM 和 Lite / Full / Heavy 权重；`setup:models` 准备 Python 模型。资源准备后，本机姿态、分割及检索摘要可离线运行，云端指导和外部视频链接仍需要联网。模型来源、大小与校验值见 `web/static/models/manifest.json` 和 `models/manifest.json`。

## 姿态页：推荐测试流程

1. 选择“攀爬测试视频 01/02”、上传视频或开启摄像头，等待骨架和关键点数据出现。摄像头需浏览器授权。
2. 标记岩点：优先选颜色或从画面取色，检查自动预选的轮廓；点击候选可取消/恢复选择。点击漏选岩点会暂停并用所选 SAM 模型识别区域；也可选择“手动画轮廓”，沿边缘画一圈。点击已有区域选中后，可拖动移动、拖四角缩放、重画或删除，支持撤销；停止画面也可编辑。
3. 需要精细轮廓时，展开 SAM 工具，选择单点分割或批量选点。每批最多 20 点，可分批追加；FastSAM 另支持整帧候选扫描。
4. 若要带着标记继续播放，确认相机位置和缩放不变，勾选“保留标记播放：确认机位固定”，再确认候选并播放监测。姿态和手脚二维邻近持续更新。
5. 在“下一步指导”选择大模型或本地预览，填写个人提示词，点击“截取瞬间并分析”。存在已选候选时，按钮显示“确认 N 个所选候选并分析”；点击会将这些候选纳入本次快照。分割处理期间暂不能分析。
6. 对照快照、眼镜短句和详细卡片。姿态与岩点图层可分别开关，点击岩点编号可突出显示，支持“放大查看”和查看返回 JSON。

颜色识别为本机 OpenCV HSV 筛选，并非攀岩专用语义模型；衣物或背景同色也可能被选中，需要人工检查。手动标记保存完整轮廓、区域中心、包围框和面积；自动识别无结果时不再创建小点，可改用手动画轮廓。颜色重扫不覆盖已确认岩点与手动区域。手动操作说明见 [区域编辑](docs/manual-hold-regions.md)。

### 手动区域编辑（2026-10-17 更新）

画面上方的“手动修正”工具提供以下操作。新增岩点以轮廓区域显示，选中区域用黄色突出显示，附四角缩放控制柄。

| 操作 | 使用方式 |
| --- | --- |
| 点击识别区域 | 点击漏选岩点，使用当前 SAM 模型识别并加入标记，默认 MobileSAM；检查边界后可继续调整 |
| 手动画轮廓 | 选择该模式，按住鼠标或手指沿边缘画一圈，松开闭合保存；无需分割模型 |
| 移动与缩放 | 点击已有区域选中，拖动内部移动，拖动四角缩放；普通点击不再删除岩点 |
| 重画边界 | 点击“重画所选区域”并画出新轮廓，替换区域且保留原编号 |
| 删除与撤销 | 使用“删除所选岩点”；“撤销上一步”可恢复完整区域及调整前的数据 |
| 取消未完成操作 | 按 Esc 或取消触摸手势，未完成轮廓不保存 |

自动识别失败、没有包含点击位置的轮廓，或区域超过画面 15% 时，提示改用手画或重新点击，不生成替代小点。手画的过小、退化或交叉轮廓不保存。已保存区域同步参与二维邻近计算、固定机位播放监测、指导快照和 JSON 导出；镜像预览不改变原始图像坐标。

**固定机位是保留静态岩点监测的前提。** 单帧标记不要求固定机位；未确认固定机位就恢复播放时，属于暂停帧的标记会被丢弃。切换视频会清空旧标记。当前没有移动相机配准或 SAM 视频掩膜传播，不能把固定机位结果直接套到随头部移动的眼镜摄像头。

操作细节：[颜色与手动标记](docs/color-hold-marking.md) · [SAM 分割与批量选点](docs/sam-segmentation.md)。

## 姿态模型与测量数据

| 可切换模型 | 原生关键点 | 执行位置 | M2 网页处理帧率参考 |
| --- | ---: | --- | ---: |
| MediaPipe Lite（默认） | 33 | 浏览器 Worker，CPU/WASM | 27.0–28.7 FPS |
| MediaPipe Full | 33 | 浏览器 Worker，CPU/WASM | 25.0–26.4 FPS |
| MediaPipe Heavy | 33 | 浏览器 Worker，CPU/WASM | 8.9–11.3 FPS |
| RTMPose-s Halpe26 | 26 | 本机 YOLO 人员框 MPS + ONNX 姿态 CPU | 13.9–15.5 FPS |
| RTMPose-m Halpe26 | 26 | 本机 YOLO 人员框 MPS + ONNX 姿态 CPU | 7.3–12.0 FPS |
| YOLO26n-pose | 17 | 本机 PyTorch MPS，部分算子 CPU 回退 | 16.9–20.0 FPS |

以上来自两段视频的短采样，包含视频处理、推理、传输与绘制，不是持续性能保证。切换模型会停止当前输入并清空本轮数据，需要重新选择输入。原生点数不同；缺失点保留为空，不补造脚尖等观测。

可选分割模型为 **FastSAM-s、MobileSAM、SAM2.1 Tiny**。两段视频的接口内推理耗时中位数分别约 141–203 ms、289–295 ms、744–799 ms，分割按需运行，不是每帧持续分割。SAM2.1 Tiny 在本机使用 MPS 配合 CPU 算子回退。ViTPose+ Large 和 SAM3.1 未作为当前网页可选模型接入。

网页显示关键点坐标、置信度/可见度、10 个二维关节角、肩髋几何中心、髋部横向偏移、肢体伸展、手脚间距，以及固定机位下的移动速度、低位移时长和岩点邻近。JSON 保存当前帧及原生输出；CSV 保存最近 1800 个采样帧的关键点记录。

测量边界：

- 肩髋几何中心是重心观察代理，不是实测人体质量中心；二维角度和模型相对深度不是三维测量。
- 手脚接近岩点不等于抓牢、踩稳或承重；低位移不能自动区分休息、读线和卡住。
- 关键点低于当前 0.5 门槛、超出画面或骨段退化时，不计算对应角度。不同模型分数未经统一校准，不能直接比较。
- 多人、遮挡和背身可能导致漏检或目标切换；当前没有可靠的跨遮挡身份追踪、IMU 融合、受力或离墙距离测量。

实测与公式：[M2 模型报告](docs/model-benchmark-m2.md) · [本地模型与攀岩指标](docs/local-models-and-climbing.md)。

## 大模型指导：配置、输入与双版输出

当前链路：

```text
摄像头 / 视频
  → 本机人体姿态 + 颜色 / SAM / 手动岩点
  → 冻结同帧原图、岩点编号图与结构化观测
  → 检索攀岩知识 + 用户提示词
  → JoyMaas Qwen3.6 → 动作与引用校验
  → 网页眼镜短句预览 + 详细指导卡片
```

### 配置 JoyMaas

参考 [.env.example](.env.example)，在项目根目录 `.env` 填写以下字段；已有文件时只修改对应字段：

```dotenv
CLIMBCUE_COACH_BASE_URL=https://modelservice.jdcloud.com/v1
CLIMBCUE_COACH_MODEL=Qwen3.6-35B-A3B
CLIMBCUE_COACH_API_KEY=填写你自己的密钥
```

指导模块每次请求读取 `.env`，保存后无需重启，环境变量优先；未指定指导配置时可复用 `CLIMBCUE_LLM_*`。密钥仅由后端使用，`.env` 已忽略提交。

在网页点击“测试模型连接”，会发出文本和蓝色图片两次小请求；成功后可测试真实快照。连接测试、真实指导及自动更新都会消耗服务商额度。未配置凭证时可用本地策略预览；来源标签会区分本地预览与大模型生成。

### 同帧输入与提示词

默认按钮自动暂停视频并冻结最后一个已完成姿态推理的画面，停止自动指导更新。请求包含同帧原图、岩点编号图、人体关键点、岩点来源/颜色/轮廓、运动观测、用户核对的支点、知识片段及个人提示词。预览镜像不改变发送的原始坐标系。

固定提示词：[climbing-coach-v1.md](docs/prompts/climbing-coach-v1.md)，由服务端实际读取。网页“我的指导提示词”最多 3000 字，保存在本浏览器，可补充脚法、髋部和表达偏好。

大模型返回结构化动作，程序校验后生成两版：

- **眼镜简略版**：一个动作，最长 20 个 Unicode 字符，例如“先确认左手支撑”。
- **网页详细版**：同一动作的选择理由、执行条件、观测依据、尚需确认事项和知识引用。

短句和详细版来自同一动作，避免两版肢体或目标不一致。未知岩点、无效引用和不满足条件的换点动作会被拒绝；没有足够证据时可以要求观察或确认支撑。

实时结果有 5 秒时效；暂停结果标记为暂停帧预览。恢复播放、切换输入/模型、修改岩点等会撤回旧指导。可手动启用每 6 秒自动更新，但当前主要验收方式仍是一次快照分析。

已验证文本、图片及真实视频快照调用；33 个关键点与 2 个 MobileSAM 轮廓输入后，两次网页实测指导耗时约 **2.45 秒、1.72 秒**。这些是单次链路样本，不代表持续实时性能或教练评定的指导准确率。详见 [真实调用报告](docs/joymaas-live-test-2026-10-17.md) 与 [指导设计及界面说明](docs/joymaas-and-coach.md)。

### 全云端方案的当前结论

2026-10-17 最近一次对 [JoyMaas 模型目录](https://joymaas.jd.com/models) 的重试核查返回 35 个模型，未发现公开文档明确提供专用人体关键点、分割掩膜或持续目标 ID 的接口。早期保存的 41 项目录快照是历史记录。

Qwen3.6 适合图像理解与指导，JoyAI-VL-Interaction 的[官方视频交互接口](https://github.com/jd-opensource/JoyAI-VL-Interaction/blob/main/doc/api.zh-CN.md)可接收连续帧并输出文字；这些能力不能直接等同于姿态测量或 SAM 分割。当前不将普通视觉语言模型硬替换为感知层。

如果后续要求 Mac 不运行视觉模型，需要另接专用云视觉 API，或将姿态/分割服务部署到云端 GPU，再把输出交给 Qwen。**该迁移尚未实现，也未验证云端视觉延迟。**

## 攀岩知识库与视频

资料总入口：[knowledge-library/README.md](knowledge-library/README.md)。全新初始化包含 **109 张卡片**：8 张原有卡片、16 张技术知识、76 张恢复拉伸知识及 9 个 BMC 官方视频目录，另关联项目自带的 2 段测试视频。审核或导入后数量可能变化。

内容覆盖脚法、旗式、对撑、勾脚、翻越、读线、休息、岩点类型，以及前臂手腕、肩背、髋腿、踝部、睡眠、饮食补水和负荷管理。恢复专题有 **32 份独立来源的中文摘要文档**，可在[文档目录](knowledge-library/recovery/documents/INDEX.md)或网页中查看与下载。来源核对不代表临床审核。

默认采用 SQLite FTS5/BM25 词法检索与可追溯的提取式摘要，不依赖密钥；无匹配正文时返回证据不足。视频目录只保存标题、来源和官方播放链接，标注未转录，不充当已阅读的教学正文。

网页可上传 MD/TXT/SRT/VTT 或粘贴笔记、字幕，保存为 `knowledge-library/imports/` 中的草稿。按[资料维护说明](knowledge-library/README.md)核对来源并改为 reviewed，再用 CLI 入库后进入正式问答；不会自动转录视频或生成精确字幕时间轴。

### 可选大模型 RAG

知识库页的大模型 RAG 与姿态页的指导配置相互独立。**知识库接口读取进程环境变量，不自动加载根目录 `.env`。** 在启动服务前配置：

```bash
export CLIMBCUE_LLM_BASE_URL='http://127.0.0.1:11434/v1'
export CLIMBCUE_LLM_MODEL='你的模型名'
# 远程服务需要鉴权时，另设置 CLIMBCUE_LLM_API_KEY
```

再启动服务，在知识库页选择“大模型 RAG”。服务端传入检索正文、适用条件、限制与引用 ID，并校验模型引用。此独立接口的协议与引用拦截有模拟测试；不能以姿态指导的真实 Qwen 测试代替知识库 RAG 的真实服务验证。引用 ID 合法也不等于语义事实已经核实。

网页数据库为 `web/runtime/knowledge.sqlite3`；独立 CLI 默认数据库为 `knowledge-rag/runtime/knowledge.sqlite3`，维护网页库须明确指定 `--db`。服务启动只补充缺失 ID，不覆盖已有审核、修改或退役记录。

## 常见排查

- **姿态不出现**：先运行 `npm run setup:pose`；使用 Python 模型时确认安装了可选依赖并下载权重。切换模型后重新选择视频输入。
- **岩点没显示**：检查是否选中/确认候选，打开“显示岩点”，点击结果区编号或“放大查看”。手动标记现在也保存轮廓；识别失败时请使用“手动画轮廓”，无岩点时结果区会明确提示。
- **播放后标记消失**：检查是否确认固定机位；切换输入和未固定机位恢复播放会清除不再适用的标记。
- **大模型连接失败**：检查服务端密钥、账号实名认证和模型权限；401/403/429、超时、空回答及输出截断均会显示错误，不伪装成成功。
- **知识库提示未配置模型**：`CLIMBCUE_COACH_*` 只配置指导；独立 RAG 需要在启动前设置 `CLIMBCUE_LLM_*` 环境变量并重启。

## 项目布局与数据流

```text
web/                   FastAPI 服务、姿态/知识库页面、模型与指导接口、测试
knowledge-library/     技术/恢复文章、32 份中文摘要、视频目录、导入草稿
knowledge-rag/         独立检索包、种子卡片、检索评估样例
models/                Python 模型权重与清单
vision-demos-main/     原有独立视觉示例，不代表当前网页已接入全部功能
testvideos/            两段本地攀爬测试视频
scripts/               模型准备、基准与浏览器验证脚本
docs/                  设计、测量边界、模型与调用验证报告
artifacts/             本地测试报告、截图、请求样本与导出结果
```

MediaPipe 在浏览器处理；RTMPose、YOLO、SAM 和颜色识别将采样帧发送到本机服务。选择云指导后，同帧图片、姿态、岩点、提示词和检索片段会发送给配置的模型服务商；选择云 RAG 后，会发送问题及检索片段。

当前服务默认仅绑定 `127.0.0.1`，没有多人账号、远程鉴权或公网部署方案。眼镜指令 JSON 使用 `climbcue.glasses.v1`，仅用于接口预览；画面二维坐标不是眼镜三维锚点，硬件接入仍需 SDK、标定和场景配准。
