# 当前感知实现的边界

本仓库的网页使用 MediaPipe Pose Landmarker Lite / Full，在浏览器 Worker 中对单个人体逐帧推理。源码：`web/static/pose-worker.js`、`pose.js` 和 `pose-math.js`。

- 模型输出 33 个关键点；界面显示原始画面归一化 x/y 和模型可见度。JSON/CSV 同时保留原始 z，z 是模型相对深度，不能当成实测米数。
- 肘膝角度使用原始视频宽高换算为像素后计算；未达到 0.5 可见度、超出画面或零长度骨段不输出角度。
- 髋中心是左右髋关键点的图像中点，不是全身质量中心；躯干倾斜也是图像平面中的角度。
- 单人模型可能在多人场景切换目标，不提供跨遮挡身份保证。页面支持手动标记岩点及二维邻近，不自动分割岩点，不推断抓牢、踩稳、握力、真实承重或离墙距离。
- 停顿本身不能区分读线、休息与卡住。当前网页只显示固定机位下的低位移时长与停顿候选，不根据低位移判断能力、疲劳或受伤。
- 当前仓库没有 IMU 采集与融合模块。旧版移植资料提及单个腰腹 IMU，但不代表本网页具备该功能。即使只有单个躯干 IMU，也不能直接知道哪只手脚承重。
- `vision-demos-main/rock_climbing` 是另一路离线云模型流程：SAM 岩点分割、ViTPose 人体、相机配准、二维邻近接触启发式。二维邻近不是可靠接触力测量。
- `rock_climbing_3d` 需要带深度和相机内参的采集目录，普通 MP4 不能替代 LiDAR 输入。
