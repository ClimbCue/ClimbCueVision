# 手动岩点区域编辑

更新日期：2026-10-17。入口：`/pose`，画面上方的“手动修正”工具。

## 使用

1. **点击识别区域**：点击漏选的岩点，自动暂停并用 SAM 工具中当前选择的模型识别，默认 MobileSAM。仅保存包含点击位置的最小有效轮廓；空结果、失败或超过画面 15% 的区域会提示重试/手画，不退回中心点标记。
2. **手动画轮廓**：选择该模式，按住鼠标或手指沿岩点边缘画一圈，松开自动闭合保存。不依赖分割模型。过小、退化或交叉的轮廓不会保存。
3. **调整**：点击已确认区域选中，黄色轮廓表示当前区域。拖动内部移动整个轮廓，拖动四角缩放；缩放保留轮廓形状。需要改变边界形状时点“重画所选区域”，画新轮廓替换，编号保留。
4. **删除/恢复**：点击“删除所选岩点”，避免普通选择操作误删。撤销可恢复添加、移动、缩放、重画和删除前的完整数据。Esc 或触摸取消会丢弃未完成的手势。
5. **继续监测**：确认固定机位后播放，保留区域并逐帧更新人体姿态。指导快照、轮廓导出和二维邻近都使用同一份区域。

颜色及 SAM 待确认候选仍然点击取消/恢复选择，确认后才能拖动调整。手动自动识别会直接加入标记，需自行检查轮廓是否覆盖所需岩点；不满意时调整或删除。

## 数据与边界

- 手画区域保存 `polygon`、`bbox`、`area_fraction`、区域内部代表位置及稳定编号，来源为 `manual`；点击识别记录 `manual-<模型名>`。模型/颜色区域被人工修改后标记为 `manual`，在导出中保留 `original_source`。
- 所有坐标使用未镜像原始画面的归一化坐标。显示镜像只改变交互映射；边缘拖动被限制在图像范围内。
- 手画轮廓去除细小抖动，最多保存 128 个顶点；没有测量岩点三维表面、摩擦或实际承重。
- 画面轮廓按屏幕像素设置线宽，竖屏缩小时仍可见。选中区域显示填充、轮廓与四角控制柄；编号用于对应指导快照。
- 手动画的任意区域只是用户标注，不经过攀岩语义识别。测试中的人工区域用于验证交互与传输，不作为岩点真值。
