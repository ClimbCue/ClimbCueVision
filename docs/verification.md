## 已发现并修复的问题

- Worker 默认 WASM loader 不适用于模块 Worker，改为 `forVisionTasks(path, true)`。
- Chrome 对视频直接 `createImageBitmap` 出现不可用源，改为 Canvas 绘制后转移 ImageBitmap。
- 关键点表节流会在暂停时留下旧帧，改为与画面/数值同帧更新。
- 原 CLI 默认数据库路径指向不存在的 `projects/`，改为包内路径，并明确网页数据库位置。
- 原 3 张实现边界卡引用缺失模块，改为当前源码边界文档；明确本网页未接入 IMU。

## 尚未实测的能力

- 实体摄像头画面与不同人的姿态精度。模拟摄像头仅验证接口和资源释放，不能替代真人摄像头评测。
- 真实大模型服务：环境没有配置服务和密钥，仅验证模拟响应与错误引用拦截。默认检索式摘要已真实跑通。
- 第三方视频完整播放、字幕识别、逐帧理解：已核对官方页面和嵌入 ID，仅保存视频目录，不把它们当已转录语料。
- 旧云模型离线示例、LiDAR 3D、多人稳定身份和动作教学准确率未在本次验证中覆盖。

测试环境有一条 Starlette 对 httpx TestClient 的弃用提示，不影响当前 21 项测试；后续框架升级时需迁移测试客户端。
