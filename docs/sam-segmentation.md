# SAM 岩点分割

入口：http://127.0.0.1:8000/pose#segmentation 。面板在视频与下一步指导之间，默认 MobileSAM。SAM 控件已收进“SAM 精细分割”折叠区域；日常标点优先用视频上方的 [颜色自动标记 + 手动修正](color-hold-marking.md)。

1. 加载摄像头或视频，确认固定机位。
2. 在分割下拉框选择 MobileSAM、SAM 2.1 Tiny 或 FastSAM-s。
3. 推荐点“批量选多个岩点”，连续点击各个岩点，再点“分割所选 N 点”。每批最多 20 个位置，有黄色编号并可撤销最后一次选点。不同岩点分别请求分割，避免把多个正提示误当成同一个物体。结果累计，可以再追加一批；重复区域会做近似去重。也支持单点分割和 FastSAM-s 整帧扫描。
4. 在候选列表勾选所需区域，或点击画面切换最小的包含点击位置的区域。蓝色为所选、灰色为未选。点击提示自动选中一个最小命中区域；整帧扫描默认不选，避免把人或墙面自动当岩点。
5. 候选可全选/取消全选。检查轮廓后点“确认 N 个候选并播放监测”，一次完成确认和播放；也可点“确认所选为岩点”后继续追加。最多保留 100 个岩点。绿色轮廓和编号会在播放中保留，姿态和邻近每帧更新，虚线只表示二维邻近。播放期间不重复运行 SAM。手动标记支持连续点击、撤销最后一个，再点“完成标记并播放监测”。
6. “导出轮廓 JSON”保存来源、模型、帧时间、候选、多边形、包围框、投影面积和已确认岩点；姿态 JSON 同步包含这些岩点。下一步指导可继续引用确认后的岩点编号和位置。

实现限制：仅固定机位的单帧图像分割，没有 SAM 视频传播。候选轮廓不代表能抓握或踩踏的表面，标记中心也不是接触点。轮廓采用外边界近似，未表达内部孔洞；内部区域的二维距离为零，不代表实际接触。相机移动后应清除旧岩点并重新标记。大模型目前接收确认后的岩点编号和代表位置，完整轮廓用于本地邻近计算和导出。

恢复播放、切换输入、拖动进度、取消固定机位会清除未确认候选并使在途分割结果失效。确认过的静态岩点在同一输入恢复播放后保留，新输入会清空。

## 2026-10-17 实际验证

本机 M2 / 16 GiB，PyTorch MPS（不支持的算子回退 CPU）。三个真实本地模型均在项目第二段视频的大红绿岩点上返回候选，并完成选择 → 确认 → 轮廓叠加 → JSON 导出。FastSAM-s 在另一次小蓝岩点点击测试中返回零候选，说明存在漏检，不能将可运行当成准确率保证。SAM 2.1 有一次返回不相连的区域；后处理已按连通区域拆成独立候选，避免 Ultralytics `masks.xyn` 拼接不相连区域产生跨越空白的轮廓。

操作验证还包括整帧候选逐个确认、恢复播放后的延迟结果丢弃、清除岩点后同步姿态数据、固定机位门控、390 px 手机宽度。原始结果：`artifacts/sam-ui-report.json`；三个模型截图：`artifacts/sam-hold-*-overlay.png`。测试是功能验证，没有像素级人工真值，不能提供 IoU 或准确率排名；耗时含模型切换后的首次预测开销，常驻模型速度请参考 M2 基准报告。

批量标记与播放回归：`npm run test:multi-holds`，结果 `artifacts/multi-holds-report.json`，包含真实 MobileSAM 多点、追加批次、撤销、批量确认、视频循环中保留岩点并更新姿态、在途批次取消、移动端和新视频清空验证。

运行：`npm run test:segmentation`；几何测试：`npm test`；后端测试：`.venv/bin/python -m pytest -q`。
