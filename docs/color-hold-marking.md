# 颜色自动标记 + 手动修正

入口：http://127.0.0.1:8000/pose 。主要工具都在视频上下方，SAM 在“岩点候选与修正”中的折叠区域。

## 推荐操作

1. 加载视频后可直接点击画面：自动暂停并添加岩点。单帧标记和颜色识别不要求勾选固定机位，停止后保留的画面也可以编辑。
2. 点击红、绿、蓝等颜色，可多选（最多 8 色），也可使用自选颜色或“从画面取色”。选色后自动暂停当前画面，整帧查找同色候选并预选；不必逐个调用 SAM。
3. 检查蓝色轮廓，点击误选候选取消，再点可恢复。开启“手动补点 / 删点”：空白处补一个中心点，已确认岩点点一下删除；“撤销上一步”恢复上一次已确认岩点编辑。
4. 确认机位没有平移或变焦并勾选“保留标记播放：确认机位固定”，再点击“确认 N 个候选并播放监测”。勾选时不会清空已完成的标记或候选。颜色识别、SAM 和手动岩点共同保留，身体姿态逐帧更新。重新扫描只替换未确认的颜色候选，不覆盖已确认岩点和手动补点。

“调整识别范围”中可调整颜色容差及小区域过滤。容差越大越容易混入近似颜色；过滤越强越容易漏掉小脚点。选色、容差变化会自动重新预览。“按颜色找岩点”可在保留当前颜色设置的情况下再次扫描。

取色读取的是未画骨架、轮廓的原始视频帧，并处理镜像坐标。候选只在当前暂停帧有效：恢复播放或切换输入会取消待显示结果；新视频会清空旧岩点。取消固定机位会暂停并保留当前帧供编辑；未确认固定机位时直接用普通播放按钮继续，会丢弃仅属于暂停帧的标记，避免把它们用于变化后的画面。颜色偏好保留，但新视频不自动暂停，需重新点击查找。

## 实现边界

- 本机 OpenCV HSV 范围筛选、去噪和连通区域外轮廓，不调用云端，也不运行 SAM。红色色相环绕、彩色阴影、黑白灰按亮度区分。过滤小碎片及超过画面 10% 的大区域，每次最多 100 个候选。
- 这些是颜色区域候选，不是经过攀岩专用训练的语义识别。衣物和背景同色也会入选；同色相连的岩点可能合并，多色岩点可能只覆盖选中的颜色部分。轮廓不保留内部孔洞。
- 精细分割仍可用 MobileSAM / FastSAM-s / SAM 2.1 Tiny，单点结果可追加；单次 FastSAM 整帧扫描会替换未确认候选。不同来源保存在各岩点的 `source`，颜色来源还保留 `colors`。
- 选色只定位可见图像区域。二维邻近不能确认实际抓握、踩踏、承重。静态岩点不会自动跟随移动摄像机。

## 验证

`npm run test:color-holds` 在真实项目视频中测试预设多色、候选取消/恢复、手动补点/删除/撤销、重扫保留手动点、镜像取色、确认播放、延迟结果丢弃和 390 px 页面布局。报告位于 `artifacts/color-holds-report.json`。测试样例单选红色产生 9 个候选，红加蓝产生 20 个；这是候选数量，不是准确率。

后端测试 `web/tests/test_color_holds.py` 覆盖红色色相环绕、阴影、多色、不相连区域、黑白色、碎片及大背景过滤、参数和图片校验。未进行带人工真值的 IoU/准确率评估。

选点故障回归：`npm run test:hold-selection`，覆盖未勾选固定机位直接选点、视频自动暂停、晚到姿态帧不覆盖标记画面、连续补点/删除/撤销、停止帧编辑、勾选固定机位保留已有候选并播放。
